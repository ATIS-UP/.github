# 🎓 SATIS - Sistema de Alertas Tempranas en Ingeniería de Sistemas  
**Prevención, Permanencia y Graduación Académica**

---

## 📝 Descripción del Proyecto

El Sistema **SATIS** es una plataforma web técnico-académica orientada a la **prevención de la deserción estudiantil** en el programa de Ingeniería de Sistemas.

El sistema permite:

- Identificar estudiantes en riesgo mediante análisis de datos  
- Aplicar estrategias de intervención temprana  
- Apoyar la toma de decisiones institucionales basadas en evidencia  

Se fundamenta en la recolección y análisis de información:

- Sociodemográfica  
- Académica  
- Psicosocial  

---

## 🎯 Objetivo General

Desarrollar un sistema de alertas tempranas que permita **detectar, analizar y mitigar factores de riesgo de deserción estudiantil**, fortaleciendo la permanencia y graduación oportuna.

---

## 🏗️ Arquitectura del Sistema

### 🔹 Frontend
- React + Tailwind CSS  
- Interfaz responsiva  
- Formularios dinámicos  

### 🔹 Backend
- FastAPI  
- Lógica de negocio  
- Motor de alertas  

### 🔹 Base de Datos
- PostgreSQL  
- Modelo relacional orientado a:
  - Estudiantes  
  - Encuestas  
  - Periodos  
  - Históricos  

### 🔹 Cache (Opcional)
- Redis  
- Optimización de consultas  

---

### 1. 📊 Gestión de Permanencia

- Registro de deserción y retención  
- Análisis por cohortes  
- Reportes comparativos
